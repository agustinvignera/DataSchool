# DataSchool — Sitio Web

Sitio estático de DataSchool (dataschool.com.ar) generado a partir del tema WordPress custom.

## Estructura

```
index.html          ← Página principal
css/style.css       ← Estilos
js/app.js           ← JavaScript (animaciones, formulario, tema oscuro)
images/             ← Logo e imágenes
sequence/           ← Secuencia de frames para animación del hero (240 frames)
```

## Tecnologías

- HTML/CSS/JS puro (sin frameworks)
- Fuente: Space Grotesk (Google Fonts)
- Formulario: Formspree
- Hosting: GitHub Pages

## Dominio personalizado

El archivo `CNAME` contiene el dominio apuntado a este repositorio.
